## Especificación OpenAPI

La especificación OpenAPI viva y canónica se sirve desde:

**`https://app.facturadirecta.com/openapi.json`**

Esa URL es la fuente de verdad del contrato de la API. Las páginas Markdown
de este repositorio son una capa editorial encima de esa especificación:
explicaciones, ejemplos, guías y matices de comportamiento.
